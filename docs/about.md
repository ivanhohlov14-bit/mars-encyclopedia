**«Марсианская энциклопедия»** — независимый справочный интернет-ресурс, посвящённый миру Марса в цикле романов **«Письмо из Красной пыли»** (автор — Mnemis). Проект создан для систематизации и популяризации знаний о планете, её истории, географии, культуре, языках, народах, персонажах и артефактах.

Все материалы публикуются в информационных и исследовательских целях.

---

## 1. Цель проекта

<div style="background: #f8f9fa; border: 1px solid #a2a9b1; border-left: 4px solid #6C63FF; padding: 10px 16px; margin: 0 0 20px 0; border-radius: 3px; font-size: 0.9rem; line-height: 1.6; color: #54595d; font-style: italic;">

Собрать в одном месте все сведения о мире Марса и «Письма из Красной пыли» — от устройства государств до быта простых марсиан — и сделать их доступными для читателей, исследователей и авторов.

</div>

Основные задачи:

- **Систематизация** — упорядочить разрозненные сведения о Марсе в единую структуру;
- **Сохранение** — зафиксировать детали мира, которые могут быть утеряны или забыты;
- **Популяризация** — привлечь новых читателей к циклу «Письмо из Красной пыли»;
- **Исследование** — предоставить материалы для анализа и обсуждения;
- **Доступность** — обеспечить свободный доступ к информации для всех желающих.

---

## 2. Основа энциклопедии

Материалы «Марсианской энциклопедии» основаны на **глиняных табличках**, найденных историком **Хевсуром** в подземном храме долины Ксанфа. Эти артефакты содержат записи о:

- **Государствах** — Королевство Ксанф, Эдем, Серпендида, Аркадия, Утопия и другие;
- **Правителях** — династии, войны, реформы;
- **Географии** — моря, заливы, полуострова, проливы;
- **Культуре** — религия, язык, обычаи, искусство;
- **Персонажах** — исторические лица и литературные герои;
- **Событиях** — от основания первых городов до гибели цивилизации.

Дополнительные источники включают **«Летопись Хевсура»**, **«Книгу Ксанфа»** и другие тексты, упомянутые в романах.

## 3. Структура энциклопедии

Разделы «Марсианской энциклопедии» организованы по тематическому принципу:

| Раздел | Содержание |
|---|---|
| **История** | Хронология событий, эпохи, войны, династии |
| **География** | Моря, заливы, полуострова, города, регионы |
| **Государства** | Королевства, их устройство, правители, политика |
| **Культура** | Религия, язык, обычаи, искусство, быт |
| **Персонажи** | Исторические лица, литературные герои |
| **Артефакты** | Таблички, свитки, предметы быта, оружие |
| **Языки** | Марсианские языки, письменность, термины |

Каждая статья содержит **инфобокс** с ключевыми данными, **основной текст**, **таблицы**, **цитаты** из источников и **ссылки** на смежные материалы.

## 4. Принципы работы

Проект придерживается следующих принципов:

- **Точность** — все сведения проверяются по первоисточникам (табличкам, летописям, романам);
- **Нейтральность** — изложение фактов без субъективных оценок;
- **Полнота** — стремление охватить все аспекты мира;
- **Открытость** — материалы доступны для чтения и обсуждения;
- **Уважение к автору** — мир принадлежит Mnemis, энциклопедия лишь систематизирует его.

## 5. Техническая реализация

Сайт «Марсианской энциклопедии» построен на **MkDocs** — генераторе статических сайтов, оптимизированном для документации. Используется тема **Material for MkDocs** (или Read the Docs), обеспечивающая:

- **Быструю навигацию** — мгновенный поиск по всем статьям;
- **Адаптивность** — корректное отображение на ПК, планшетах и телефонах;
- **Тёмную тему** — режим «звёздного неба» для комфортного чтения;
- **Интерактивность** — пасхалки, комментарии, профили пользователей.

Хостинг осуществляется через **GitHub Pages**, что обеспечивает стабильный доступ и высокую скорость загрузки.
