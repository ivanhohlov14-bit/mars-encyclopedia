**«Марсианская энциклопедия»** — научно-художественный справочный проект, посвящённый вселенной цикла романов **«Письмо из Красной пыли»** (автор — Mnemis). В основе проекта лежит реконструкция возможной истории Марса, выполненная с опорой на актуальные научные данные из областей геологии, климатологии, астробиологии и физики планет.

Материалы энциклопедии **не являются чистым вымыслом**. Они представляют собой научно обоснованную гипотетическую модель — экстраполяцию того, какой могла бы быть жизнь на Марсе, если бы она действительно существовала в его древнюю эпоху. Все гипотезы, представленные в проекте, находятся в рамках современных научных представлений и не противоречат известным фактам о Красной планете.

---

## 1. Цель проекта

Основные задачи «Марсианской энциклопедии»:

- **Систематизация** — собрать в одном месте все сведения о мире «Письма из Красной пыли»: от устройства государств до быта простых марсиан;
- **Сохранение** — зафиксировать детали мира, которые могут быть утеряны или забыты;
- **Популяризация** — привлечь новых читателей к циклу романов и научной фантастике в целом;
- **Исследование** — предоставить материалы для анализа, обсуждения и собственных выводов;
- **Доступность** — обеспечить свободный доступ к информации для всех желающих.

Проект адресован широкой аудитории, интересующейся вопросами происхождения жизни во Вселенной, эволюции планет и возможных форм разума за пределами Земли. Энциклопедия предлагает читателю не готовые ответы, а **пространство для размышлений** — модели того, какой могла бы быть история Марса.

## 2. Источниковедческая база

Источниковедческая база энциклопедии строится на **трёх уровнях**:

| Уровень | Содержание |
|---|---|
| **Реальные научные данные** | Геологическая история Марса, климатические изменения, наличие жидкой воды в прошлом, обнаружение органических молекул, перхлоратов и метана в атмосфере |
| **Художественная концепция** | Расшифровка глиняных табличек, найденных историком Хевсуром в подземном храме долины Ксанфа, описывающих историю марсианской цивилизации в Эпоху Умирания |
| **Логическая реконструкция** | Моделирование биологических, социальных и культурных процессов, которые могли бы иметь место в условиях низкой гравитации (0,38 g), разрежённой атмосферы и постепенного угасания планеты |

## 3. Структура энциклопедии

Разделы организованы по тематическому принципу:

| Раздел | Содержание |
|---|---|
| **История** | Хронология событий, эпохи, войны, династии |
| **География** | Моря, заливы, полуострова, города, регионы |
| **Государства** | Королевства, их устройство, правители, политика |
| **Культура** | Религия, язык, обычаи, искусство, быт |
| **Персонажи** | Исторические лица, литературные герои |
| **Артефакты** | Таблички, свитки, предметы быта, оружие |
| **Языки** | Марсианские языки, письменность, термины |

Каждая статья содержит инфобокс с ключевыми данными, основной текст, таблицы, цитаты из источников и ссылки на смежные материалы.

## 4. Принципы работы

Проект придерживается следующих принципов:

- **Научная обоснованность** — все гипотезы опираются на реальные данные и не противоречат современному знанию;
- **Точность** — сведения проверяются по первоисточникам (табличкам, летописям, романам);
- **Нейтральность** — изложение фактов без субъективных оценок;
- **Полнота** — стремление охватить все аспекты мира;
- **Открытость** — материалы доступны для чтения и обсуждения;
- **Уважение к автору** — мир принадлежит Mnemis, энциклопедия лишь систематизирует его.

## 5. Техническая реализация

Сайт «Марсианской энциклопедии» построен на **MkDocs** — генераторе статических сайтов, оптимизированном для документации. Используется тема **Material for MkDocs** (или Read the Docs), обеспечивающая:

- **Быструю навигацию** — мгновенный поиск по всем статьям;
- **Адаптивность** — корректное отображение на ПК, планшетах и телефонах;
- **Тёмную тему** — режим «звёздного неба» для комфортного чтения;
- **Интерактивность** — пасхалки, комментарии, профили пользователей.

Хостинг осуществляется через **GitHub Pages**, что обеспечивает стабильный доступ и высокую скорость загрузки.
