<h2 class="mh-h2 mh-observe">
  <span class="mh-h2-num">01</span>
  Кровь потечёт не туда, куда должна
</h2>

<div class="mh-section mh-observe">
  <div class="mh-section-img">
    <img src="/assets/images/section-blood.jpg" 
         alt="Кровообращение в слабой гравитации" loading="lazy">
    <div class="mh-section-img-badge">⚕️ Медицина</div>
  </div>
  <div class="mh-section-text">
    <p>
      На Земле гравитация <strong>тянет всю кровь вниз</strong> — к ногам.
      Сердце работает как насос, который постоянно качает её обратно.
      На Марсе гравитация всего <strong>38% от земной</strong>.
    </p>
    <p>
      Результат: <strong>2 литра крови</strong> из нижней части тела устремляются
      в грудь и голову. Лицо отекает, вены на шее вздуваются, нос закладывает.
      Космонавты на МКС называют это <em>«bird legs»</em> — «птичьи ноги»,
      потому что ноги становятся тонкими, а верх тела — раздутым.
    </p>
    <div class="mh-fact-box">
      <div class="mh-fact-box-icon">📊</div>
      <div class="mh-fact-box-body">
        <strong>За 6 месяцев на МКС:</strong> объём плазмы крови падает на 22%.
        Сердце уменьшается на 9,4%. Организм считает, что «крови слишком много»
        и сокращает её производство.
      </div>
    </div>
  </div>
</div>

<h2 class="mh-h2 mh-observe">
  <span class="mh-h2-num">02</span>
  Кости исчезают изнутри
</h2>

<div class="mh-section mh-section-reverse mh-observe">
  <div class="mh-section-img">
    <img src="/assets/images/section-bones.jpg" 
         alt="Деградация костной массы" loading="lazy">
    <div class="mh-section-img-badge">🦴 Остеопороз</div>
  </div>
  <div class="mh-section-text">
    <p>
      Кости — живая ткань. Каждый день они разрушаются и строятся заново.
      Гравитация — сигнал для них: <em>«будьте прочнее»</em>. Без гравитации
      этот сигнал пропадает.
    </p>
    <p>
      <strong>1–1,5% костной массы в месяц.</strong> За год полёта — до 20%.
      Это как если бы здоровый человек в 30 лет стал 70-летним стариком
      по состоянию скелета.
    </p>
    <p>
      Хуже всего — <strong>тазовые кости и позвонки</strong>. Они теряют
      кальций быстрее всех. После 3 лет в слабой гравитации встать с постели
      без поддержки почти невозможно.
    </p>
    <div class="mh-fact-box mh-fact-box-warning">
      <div class="mh-fact-box-icon">⚠️</div>
      <div class="mh-fact-box-body">
        <strong>Обратный путь:</strong> на Земле восстановление идёт в 2–3 раза
        медленнее. То, что потеряно за год на Марсе, восстанавливается 2–3 года.
        Полное восстановление — <strong>не гарантировано</strong>.
      </div>
    </div>
  </div>
</div>

    </p>
    <p>

  <span class="mh-h2-num">04</span>
  Радиация в 15 раз выше безопасной
</h2>

<div class="mh-section mh-section-reverse mh-observe">
  <div class="mh-section-img">
    <img src="/assets/images/section-radiation.jpg" 
         alt="Космическая радиация" loading="lazy">
    <div class="mh-section-img-badge">☢️ Радиация</div>
  </div>
  <div class="mh-section-text">
    <p>
      У Марса <strong>нет магнитного поля</strong>. Атмосфера в 100 раз
      тоньше земной. Это значит — космические лучи и солнечные вспышки
      доходят до поверхности без фильтра.
    </p>
    <p>
      <strong>Доза за полёт туда-обратно:</strong> ~300 миллизивертов (мЗв).
      Это <strong>в 15 раз больше</strong> безопасного уровня для человека
      (20 мЗв в год).
    </p>
    <p>
      <strong>Последствия:</strong> повышенный риск онкологии, катаракты,
      повреждение ДНК, раннее старение. За 3 года на Марсе — риск
      рака лёгких вырастает в <strong>2–3 раза</strong>.
    </p>
    <div class="mh-fact-box mh-fact-box-warning">
      <div class="mh-fact-box-icon">☢️</div>
      <div class="mh-fact-box-body">
        <strong>Вода — лучший щит.</strong> Полметра воды вокруг жилого модуля
        снижают радиацию в 2 раза. Именно поэтому первую базу хотят
        строить там, где лёд под ногами — в Amazonis Planitia.
      </div>
    </div>
  </div>
</div>

  </div>
  <div class="mh-section-text">
    <p>

      гормональные нарушения.
    </p>
    <p>
      Частицы — <strong>1/50 миллиметра</strong>. Они проходят через любые
      фильтры, забиваются в лёгкие, накапливаются годами. Отдышаться
      марсианским воздухом без фильтра — как выкурить пачку сигарет
      с пеплом.
    </p>
    <p>
      Плюс — пыль <strong>электризуется</strong> и прилипает к скафандру.
      Космонавты не смогут снять его, не занеся пыль внутрь жилого модуля.
    </p>
  </div>
</div>

<h2 class="mh-h2 mh-observe">
  <span class="mh-h2-num">07</span>
  Без скафандра — 15 секунд до потери сознания
</h2>

<div class="mh-section mh-observe">
  <div class="mh-section-img">
    <img src="/assets/images/section-suit.jpg" 
         alt="Скафандр для Марса" loading="lazy">
    <div class="mh-section-img-badge">🚀 Скафандр</div>
  </div>
  <div class="mh-section-text">
    <p>
      Миф: «человек мгновенно закипает в вакууме». <strong>Не закипает.</strong>
      Кожа и сосуды достаточно эластичны, чтобы выдержать давление изнутри.
    </p>
    <p>
      Реальность: без скафандра человек теряет сознание за
      <strong>10–15 секунд</strong>. Смерть — за <strong>1–2 минуты</strong>
      от гипоксии, если не подать кислород.
    </p>
    <p>
      <strong>Что почувствует человек:</strong> язык и слюна «закипают»
      на языке (небольшая шипучка), лёгкие начинают расширяться от
      недостатка давления, кровь закипает в лёгких, если не выдохнуть.
    </p>
    <p>
      Спасти человека можно — если в течение 30 секунд надеть маску
      с кислородом. Просто «подышать марсианским воздухом» не получится:
      <strong>95% CO₂</strong>, давление в 170 раз ниже земного.
    </p>
  </div>
</div>

<h2 class="mh-h2 mh-observe">❓ Частые вопросы</h2>
<div class="mh-faq mh-observe">
  <details class="mh-faq-item">
    <summary>
      <span>Можно ли забеременеть на Марсе?</span>
      <span class="mh-faq-icon">▸</span>
    </summary>
    <div class="mh-faq-answer">
      Технически — возможно. Но <strong>радиация повреждает ДНК</strong>,
      а слабая гравитация меняет развитие плода. Никто не знает, что
      произойдёт с ребёнком. Пока это <strong>запрещено во всех программах</strong>.
    </div>
  </details>

  <details class="mh-faq-item">
    <summary>
      <span>Сколько живёт человек на Марсе?</span>
      <span class="mh-faq-icon">▸</span>
    </summary>
    <div class="mh-faq-answer">
      Расчёты разные. При <strong>полной защите от радиации</strong>
      и замкнутом жизнеобеспечении — <strong>15–25 лет</strong>.
      Без защиты от радиации — <strong>3–5 лет</strong> до появления
      серьёзных проблем со здоровьем.
    </div>
  </details>

  <details class="mh-faq-item">
    <summary>
      <span>Что случится с телом после смерти?</span>
      <span class="mh-faq-icon">▸</span>
    </summary>
    <div class="mh-faq-answer">
      Тело <strong>не разложится</strong> — нет бактерий и кислорода.
      Оно высохнет, превратится в мумию. Пыль и радиация медленно
      изменят кожу и волосы. Через 100 лет — просто «статуя».
    </div>
  </details>

  <details class="mh-faq-item">
    <summary>
      <span>Как часто можно ходить без скафандра?</span>
      <span class="mh-faq-icon">▸</span>
    </summary>
    <div class="mh-faq-answer">
      <strong>Никогда.</strong> Даже на 5 секунд нельзя. Атмосфера не просто
      «разреженная» — она смертельна. Нужна полная герметизация
      жилого модуля или скафандр.
    </div>
  </details>

  <details class="mh-faq-item">
    <summary>
      <span>Можно ли дышать через специальную маску?</span>
      <span class="mh-faq-icon">▸</span>
    </summary>
    <div class="mh-faq-answer">
      Нет. Марсианский воздух — <strong>95% CO₂</strong> и 0,16% кислорода.
      Плюс давление в 170 раз ниже. Даже если фильтровать CO₂,
      нужно <strong>компенсировать давление</strong> — это уже не маска,
      а целая система жизнеобеспечения.
    </div>
  </details>

  <details class="mh-faq-item">
    <summary>
      <span>Правда, что человек «закипает» в вакууме?</span>
      <span class="mh-faq-icon">▸</span>
    </summary>
    <div class="mh-faq-answer">
      Нет. Кровь <strong>не закипает</strong> — сосуды эластичны. Кожа
      защищает тело. Но <strong>слюна и слёзы</strong> действительно
      «вспениваются» из-за низкого давления. Это не смертельно,
      но неприятно.
    </div>
  </details>
</div>

(function(){

window.__marsHumanLoaded = true;

/* ═══ SCROLL OBSERVE ═══ */
function initObserve(){
  var items = document.querySelectorAll('.mh-observe');
  if (!items.length) return;
  if (!('IntersectionObserver' in window)){
    items.forEach(function(el){ el.classList.add('mh-visible'); });
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        e.target.classList.add('mh-visible');
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.12, rootMargin: '0px 0px -40px 0px' });
  items.forEach(function(el){ io.observe(el); });
}

/* ═══ СЧЁТЧИКИ ═══ */
function animateCounter(el){
  var target = parseFloat(el.dataset.target || '0');
  var decimals = parseInt(el.dataset.decimals || '0', 10);
  var duration = 1800;
  var start = performance.now();
  function tick(now){
    var p = Math.min((now - start) / duration, 1);
    var eased = 1 - Math.pow(1 - p, 3);
    var val = target * eased;
    el.textContent = decimals > 0 ? val.toFixed(decimals) : Math.round(val).toString();
    if (p < 1) requestAnimationFrame(tick);
    else el.textContent = decimals > 0 ? target.toFixed(decimals) : target.toString();
  }
  requestAnimationFrame(tick);
}
function initCounters(){
  var counters = document.querySelectorAll('.mh-counter');
  if (!counters.length) return;
  if (!('IntersectionObserver' in window)){
    counters.forEach(animateCounter);
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        animateCounter(e.target);
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.5 });
  counters.forEach(function(el){ io.observe(el); });
}

/* ═══ КАЛЬКУЛЯТОР ВЕСА ═══ */
function initWeightCalc(){
  var slider = document.getElementById('mh-weight');
  if (!slider) return;

  var valueEl = document.getElementById('mh-weight-value');
  var cards = document.querySelectorAll('.mh-calc-card');

  // Гравитация относительно Земли
  var grav = { mars: 0.379, moon: 0.165, jupiter: 2.528, sun: 27.9 };

  function fmt(n){
    if (n >= 1000){
      return n.toFixed(0).replace(/\B(?=(\d{3})+(?!\d))/g, ' ');
    }
    return n.toFixed(1);
  }

  function update(){
    var w = parseInt(slider.value, 10) || 75;
    valueEl.textContent = w;
    cards.forEach(function(card){
      var planet = card.dataset.planet;
      var g = grav[planet] || 1;
      var val = w * g;
      var el = card.querySelector('.mh-weight-val');
      if (el) el.textContent = fmt(val);
    });
  }

  slider.addEventListener('input', update);
  update();
}

/* ═══ ЗАПУСК ═══ */

  initObserve();
  initCounters();
  initWeightCalc();
  console.log('⚕️ Статья «Человек на Марсе» загружена');
}

if (document.readyState === 'loading'){
  document.addEventListener('DOMContentLoaded', init);
} else {
  init();
}

})();
