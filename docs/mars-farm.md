<h2 class="mf-h2 mf-observe">
  <span class="mf-h2-num">01</span>
  Три главных препятствия
</h2>

<div class="mf-problems mf-observe">
  <div class="mf-problem-card">
    <div class="mf-problem-header">
      <div class="mf-problem-icon">☢️</div>
      <div class="mf-problem-num">01</div>
    </div>
    <div class="mf-problem-title">Радиация</div>
    <div class="mf-problem-text">
      На поверхности — в <strong>15 раз выше нормы</strong>.
      Без защиты растения мутируют за несколько поколений.
      Решение: <strong>толща реголита</strong> над теплицей + подземные
      фермы в лавовых трубках.
    </div>
  </div>

  <div class="mf-problem-card">
    <div class="mf-problem-header">
      <div class="mf-problem-icon">🧪</div>
      <div class="mf-problem-num">02</div>
    </div>
    <div class="mf-problem-title">Перхлораты</div>
    <div class="mf-problem-text">
      В марсианском грунте — <strong>0,5–1% перхлоратов</strong>
      (ClO₄). Это токсичные соли, которые разрушают щитовидную железу.
      Просто «посадить в грунт» не получится — нужно <strong>промывать</strong>
      или использовать гидропонику.
    </div>
  </div>

  <div class="mf-problem-card">
    <div class="mf-problem-header">
      <div class="mf-problem-icon">❄️</div>
      <div class="mf-problem-num">03</div>
    </div>
    <div class="mf-problem-title">Холод и давление</div>
    <div class="mf-problem-text">
      На поверхности — <strong>−63 °C</strong> и давление
      в <strong>170 раз</strong> ниже земного. Вода закипает при 0 °C.
      Решение: герметичные купола с подогревом и стабилизацией
      давления до <strong>50–101 кПа</strong>.
    </div>
  </div>
</div>

<h2 class="mf-h2 mf-observe">⚙️ Как работает марсианская ферма</h2>

<div class="mf-how mf-observe">
  <div class="mf-how-item">
    <div class="mf-how-num">01</div>
    <div class="mf-how-icon">🏠</div>
    <div class="mf-how-title">Герметичный купол</div>
    <div class="mf-how-text">
      Стекло или прозрачный пластик с защитой от радиации.
      Давление внутри — <strong>50 кПа</strong> (половина земного).
      Достаточно для растений, но не для человека — работать в скафандре.
    </div>
  </div>

  <div class="mf-how-item">
    <div class="mf-how-num">02</div>
    <div class="mf-how-icon">💡</div>
    <div class="mf-how-title">Фиолетовый LED</div>
    <div class="mf-how-text">
      Марсианский свет <strong>в 1,5 раза слабее</strong> земного.
      Растения не получат достаточно энергии. Решение — фиолетовые
      LED-лампы: красный + синий спектр, самый эффективный для фотосинтеза.
    </div>
  </div>

  <div class="mf-how-item">
    <div class="mf-how-num">03</div>
    <div class="mf-how-icon">💧</div>
    <div class="mf-how-title">Гидропоника</div>
    <div class="mf-how-text">
      Растения растут в питательном растворе без почвы.
      Так <strong>решается проблема перхлоратов</strong> и экономится
      <strong>90% воды</strong>. Именно так NASA планирует первую марсианскую ферму.
    </div>
  </div>

  <div class="mf-how-item">
    <div class="mf-how-num">04</div>
    <div class="mf-how-icon">♻️</div>
    <div class="mf-how-title">Замкнутый цикл</div>
    <div class="mf-how-text">
      Отходы → компост → удобрения → растения → еда → отходы.
      <strong>Ничего не выбрасывается.</strong> Это критично: доставка
      с Земли стоит $1 млн за кг.
    </div>
  </div>
</div>

<h2 class="mf-h2 mf-observe">❓ Частые вопросы</h2>
<div class="mf-faq mf-observe">
  <details class="mf-faq-item">
    <summary>
      <span>Можно ли есть марсианскую картошку из «Марсианина»?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      В фильме Марк Уотни вырастил картошку в марсианском грунте,
      удобренном... собой. <strong>В реальности это невозможно</strong>:
      перхлораты в грунте убьют растение. Нужна либо промывка,
      либо гидропоника. Но сама идея — правильная.
    </div>
  </details>

  <details class="mf-faq-item">
    <summary>
      <span>Сколько воды нужно для марсианской фермы?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      С гидропоникой и рециркуляцией — <strong>1–2 литра на кг урожая</strong>.
      Для фермы на 10 человек: <strong>~500 литров в сутки</strong>.
      Источник — водяной лёд под поверхностью (Amazonis Planitia).
    </div>
  </details>

  <details class="mf-faq-item">
    <summary>
      <span>Что будет с растением при марсианском давлении?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      При давлении <strong>50 кПа</strong> (половина земного) растения
      чувствуют себя нормально. Проблема не в давлении, а в
      <strong>низком парциальном давлении CO₂</strong> — нужно
      добавлять его искусственно.
    </div>
  </details>

  <details class="mf-faq-item">
    <summary>
      <span>Можно ли опылять растения без пчёл?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      Да. Три способа: <strong>вручную</strong> (кисточкой),
      <strong>вибрацией</strong> (электро-щётка), <strong>шмелями</strong>
      (их уже возили на МКС). Пчёлы не подходят — слишком сложно
      содержать улей в невесомости.
    </div>
  </details>

  <details class="mf-faq-item">
    <summary>
      <span>Какой урожай можно получить с 1 м²?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      Зависит от культуры: <strong>картофель — 3 кг/м²</strong>,
      <strong>салат — 5 кг/м²</strong>, <strong>томаты — 10 кг/м²</strong>,
      <strong>пшеница — 0,5 кг/м²</strong>. В марсианских условиях
      с LED-подсветкой эти цифры могут быть выше за счёт
      24-часового цикла.
    </div>
  </details>

  <details class="mf-faq-item">
    <summary>
      <span>Можно ли вырастить дерево на Марсе?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      Технически — да, но нужен <strong>большой объём</strong>
      (для яблони — 10–20 м³ грунта) и <strong>10+ лет</strong>.
      В первой колонии деревья не появятся. Это задача для
      второй волны колонизации.
    </div>
  </details>

  <details class="mf-faq-item">
    <summary>
      <span>Что делать с отходами жизнедеятельности?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      Компостирование + <strong>биореактор</strong>. Отходы
      перерабатываются в питательную среду для гидропоники.
      На МКС уже работает система «Ecostress» — аналог такого
      цикла. Проблема решаема.
    </div>
  </details>

  <details class="mf-faq-item">
    <summary>
      <span>Сколько энергии нужно для фермы?</span>
      <span class="mf-faq-icon">▸</span>
    </summary>
    <div class="mf-faq-answer">
      Для LED-освещения — <strong>100–150 Вт на м²</strong>.
      Для 100 м² фермы: <strong>12 кВт непрерывно</strong>.
      Это 290 кВт·ч в сутки. Требуется солнечная станция
      на 40–60 кВт или компактный ядерный реактор (как
      у NASA Kilopower — 10 кВт на 1 установку).
    </div>
  </details>
</div>

<div class="mf-conclusion mf-observe">
  <div class="mf-conclusion-icon">🌾</div>
  <div class="mf-conclusion-body">
    <div class="mf-conclusion-title">Что это значит для будущего</div>
    <p>
      Марсианская ферма — <strong>не мечта, а инженерная задача</strong>.
      Все компоненты уже работают на МКС. Главная проблема —
      не «как вырастить», а <strong>«как сделать это самодостаточно»</strong>.
    </p>
    <p style="margin-top:12px;">
      Первая ферма появится вместе с первой пилотируемой миссией.
      Она будет <strong>небольшой</strong> — 20–50 м², гидропоника,
      салат и помидоры. И это станет началом новой эпохи:
      <strong>человек сможет выжить там, где раньше только умирал</strong>.
    </p>
    <p style="margin-top:12px;">

/* ═══ SCROLL OBSERVE ═══ */
function initObserve(){
  var items = document.querySelectorAll('.mf-observe');
  if (!items.length) return;
  if (!('IntersectionObserver' in window)){
    items.forEach(function(el){ el.classList.add('mf-visible'); });
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        e.target.classList.add('mf-visible');
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.1, rootMargin: '0px 0px -40px 0px' });
  items.forEach(function(el){ io.observe(el); });
}

/* ═══ СЧЁТЧИКИ ═══ */
function animateCounter(el){
  var target = parseFloat(el.dataset.target || '0');
  var decimals = parseInt(el.dataset.decimals || '0', 10);
  var duration = 1800;
  var start = performance.now();
  function tick(now){
    var p = Math.min((now - start) / duration, 1);
    var eased = 1 - Math.pow(1 - p, 3);
    var val = target * eased;
    el.textContent = decimals > 0 ? val.toFixed(decimals) : Math.round(val).toString();
    if (p < 1) requestAnimationFrame(tick);
    else el.textContent = decimals > 0 ? target.toFixed(decimals) : target.toString();
  }
  requestAnimationFrame(tick);
}
function initCounters(){
  var counters = document.querySelectorAll('.mf-counter');
  if (!counters.length) return;
  if (!('IntersectionObserver' in window)){
    counters.forEach(animateCounter);
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        animateCounter(e.target);
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.5 });
  counters.forEach(function(el){ io.observe(el); });
}

function initSimulator(){
  var slider = document.getElementById('mf-area');
  if (!slider) return;
  var valueEl = document.getElementById('mf-area-value');
  var peopleEl = document.getElementById('mf-people');
  var kgEl = document.getElementById('mf-kg-year');
  var waterEl = document.getElementById('mf-water');
  var powerEl = document.getElementById('mf-power');

  // Нормы NASA
  var M2_PER_PERSON = 50;         // м² на человека для полного пропитания
  var KG_PER_M2_YEAR = 3;         // кг урожая с м² в год (среднее)
  var WATER_L_PER_M2_DAY = 4;     // литров на м² в сутки
  var POWER_W_PER_M2 = 100;       // ватт на м² для LED

  function fmt(n){
    if (n >= 1000) return Math.round(n).toString().replace(/\B(?=(\d{3})+(?!\d))/g, ' ');
    if (n >= 100) return Math.round(n).toString();
    return n.toFixed(1);
  }

  function update(){
    var area = parseInt(slider.value, 10) || 200;
    valueEl.textContent = area;

    var people = area / M2_PER_PERSON;
    var kgYear = area * KG_PER_M2_YEAR;

    var powerKw = (area * POWER_W_PER_M2) / 1000;       // кВт

    peopleEl.textContent = Math.round(people);
    kgEl.textContent = fmt(kgYear);
    waterEl.textContent = waterTons.toFixed(1);
    powerEl.textContent = Math.round(powerKw);
  }

  slider.addEventListener('input', update);
  update();
}

/* ═══ КАЛЬКУЛЯТОР УРОЖАЯ ═══ */
var harvestSelected = {};

function initHarvestPicker(){
  var picker = document.getElementById('mf-harvest-picker');
  if (!picker) return;

  // По умолчанию выбираем топ-4
  harvestSelected = { potato: true, wheat: true, lettuce: true, tomato: true };

  picker.innerHTML = CROPS.map(function(c){
    var active = harvestSelected[c.id] ? ' active' : '';
    return '<button type="button" class="mf-harvest-pill' + active + '" data-crop="' + c.id + '">' +
      c.emoji + ' ' + c.name + '</button>';
  }).join('');

  picker.querySelectorAll('.mf-harvest-pill').forEach(function(pill){
    pill.addEventListener('click', function(){
      var id = pill.dataset.crop;
      if (harvestSelected[id]){
        delete harvestSelected[id];
        pill.classList.remove('active');
      } else {
        harvestSelected[id] = true;
        pill.classList.add('active');
      }
      updateHarvest();
    });
  });
}

function updateHarvest(){
  var AREA = 100; // м² фиксированная площадь
  var PEOPLE_KCAL = 2800; // ккал/день на человека
  var DAYS_YEAR = 365;

  var totalKcalYear = 0;
  var totalMassYear = 0;

  CROPS.forEach(function(c){
    if (!harvestSelected[c.id]) return;
    var kg = c.kgPerM2 * AREA / CROPS.filter(function(x){ return harvestSelected[x.id]; }).length;
    totalMassYear += kg * (DAYS_YEAR / c.days); // учёт циклов за год
    totalKcalYear += kg * c.kcalPerKg * (DAYS_YEAR / c.days);
  });

  var kcalPerDay = totalKcalYear / DAYS_YEAR;
  var people = kcalPerDay / PEOPLE_KCAL;

  document.getElementById('mf-harvest-cal').textContent = Math.round(kcalPerDay).toLocaleString('ru-RU');
  document.getElementById('mf-harvest-people').textContent = people.toFixed(2);
  document.getElementById('mf-harvest-mass').textContent = Math.round(totalMassYear).toLocaleString('ru-RU');

  var barPercent = Math.min(people / 4 * 100, 100); // шкала: 4 человека = 100%
  document.getElementById('mf-harvest-bar').style.width = barPercent + '%';
}

/* ═══ ЗАПУСК ═══ */
function init(){
  initObserve();
  initCounters();
  initSimulator();
  renderCrops();
  initHarvestPicker();
  updateHarvest();
  console.log('🌱 Марсианская ферма загружена. Культур: ' + CROPS.length);
}

if (document.readyState === 'loading'){
  document.addEventListener('DOMContentLoaded', init);
} else {
  init();
}

})();
