# Политика конфиденциальности

Мы собираем только ту информацию, которую вы предоставляете при регистрации:

- **Email** — для входа и связи с вами.
- **Имя пользователя** — для отображения в профиле.
- **Пароль** — хранится в зашифрованном виде на серверах Supabase.

Ваши данные не передаются третьим лицам. Вы можете удалить свой аккаунт в любой момент, написав нам на [email].
