<h2 class="rd-h2 rd-observe">
  <span class="rd-h2-num">01</span>
  Траектория Гомана — путь через половину орбиты
</h2>

<div class="rd-section rd-observe">
  <div class="rd-section-img">
    <img src="/assets/images/section-trajectory.jpeg"

    <div class="rd-section-img-badge">🚀 Траектория</div>
  </div>
  <div class="rd-section-text">
    <p>
      Космический корабль не летит «по прямой». Он движется по
      <strong>эллипсу</strong> — половине орбиты вокруг Солнца. Такой путь
      называется <strong>траекторией Гомана</strong>, и он самый
      экономичный по топливу.
    </p>
    <p>

      пройдёт свою орбиту, а Марс — свою. Корабль встречает Марс
      <strong>в нужной точке</strong> — как будто по расписанию.
    </p>
    <div class="rd-fact-box">
      <div class="rd-fact-box-icon">📊</div>
      <div class="rd-fact-box-body">

        огромных затрат топлива. Плавная кривая вокруг Солнца — в
        <strong>3–5 раз дешевле</strong>. Космос не прощает спешки.
      </div>
    </div>
  </div>

<h2 class="rd-h2 rd-observe">
  <span class="rd-h2-num">02</span>
  Топливо — самая дорогая часть полёта
</h2>

<div class="rd-section rd-section-reverse rd-observe">
  <div class="rd-section-img">
    <img src="/assets/images/section-fuel.jpeg" 
         alt="Ракетный двигатель" loading="lazy">
    <div class="rd-section-img-badge">🛢 Топливо</div>
  </div>
  <div class="rd-section-text">
    <p>
      Ракета — это <strong>90% топлива по массе</strong>. Starship весит
      5000 т, но из них <strong>1200 т — топливо</strong>, а полезная
      нагрузка — всего 100 т.
    </p>
    <p>
      Используется <strong>жидкий метан + жидкий кислород</strong>. Это
      не случайно: метан можно производить прямо на Марсе из атмосферы
      (CO₂ + водород). Значит, для возврата топливо не нужно везти с Земли.
    </p>
    <div class="rd-fact-box">
      <div class="rd-fact-box-icon">⛽</div>
      <div class="rd-fact-box-body">
        <strong>Сравнение:</strong> для полёта на Луну нужно 2500 т топлива.
        До Марса — <strong>1200 т</strong> (но с дозаправкой на орбите).
        Без дозаправки Starship долетит только с полезной нагрузкой 50 т.
      </div>
    </div>
  </div>
</div>

<h2 class="rd-h2 rd-observe">
  <span class="rd-h2-num">04</span>
  Starship — почему он фаворит
</h2>

<div class="rd-section rd-section-reverse rd-observe">
  <div class="rd-section-img">
    <img src="/assets/images/section-starship.jpeg" 
         alt="Starship на стартовой площадке" loading="lazy">
    <div class="rd-section-img-badge">⭐ Starship</div>
  </div>
  <div class="rd-section-text">
    <p>
      Starship от SpaceX — <strong>самая большая ракета в истории</strong>.
      Она может вывести на орбиту 100–150 тонн полезной нагрузки.
      И, главное, <strong>многоразовая</strong> — это снижает стоимость
      запуска в 10–20 раз.
    </p>
    <p>
      Илон Маск обещает стоимость <strong>до $10 млн за запуск</strong>.
      Сегодня — $1,5 млрд за миссию SLS. Разница в 150 раз.
    </p>
    <div class="rd-fact-box">
      <div class="rd-fact-box-icon">💡</div>
      <div class="rd-fact-box-body">
        <strong>Дозаправка на орбите</strong> — ключевая технология. SpaceX
        планирует запустить 5–10 танкеров, чтобы дозаправить Starship
        перед полётом на Марс. Это ещё никто не делал.
      </div>
    </div>
  </div>
</div>

      нужна защита от радиации и запасы на годы вперёд.
    </div>
  </details>

  <details class="rd-faq-item">
    <summary>
      <span>Почему нельзя стартовать в любой момент?</span>
      <span class="rd-faq-icon">▸</span>
    </summary>
    <div class="rd-faq-answer">
      Потому что нужно дождаться <strong>правильного положения планет</strong>.
      Земля и Марс должны быть на таких орбитах, чтобы корабль встретился
      с Марсом в нужной точке. Это происходит раз в <strong>780 дней</strong>
      (2 года и 2 месяца).
    </div>
  </details>

  <details class="rd-faq-item">
    <summary>
      <span>Можно ли долететь быстрее?</span>
      <span class="rd-faq-icon">▸</span>
    </summary>
    <div class="rd-faq-answer">
      Технически — да, но это требует <strong>в 2–3 раза больше топлива</strong>.
      Например, ядерный двигатель мог бы сократить путь до <strong>90 дней</strong>,
      но таких двигателей пока нет в рабочем состоянии. Химические
      ракеты — не быстрее 7 месяцев.
    </div>
  </details>

  <details class="rd-faq-item">
    <summary>
      <span>Что экипаж будет делать 7 месяцев?</span>
      <span class="rd-faq-icon">▸</span>
    </summary>
    <div class="rd-faq-answer">
      Тренировки (2 часа в день — чтобы не потерять мышцы),
      научные эксперименты, ремонт систем, психологическая
      поддержка. Плюс — <strong>связь с Землёй с задержкой</strong>.
      Разговоры только текстом, фильмы, книги, игры.
    </div>
  </details>

  <details class="rd-faq-item">
    <summary>
      <span>Сколько стоит билет на Марс?</span>
      <span class="rd-faq-icon">▸</span>
    </summary>
    <div class="rd-faq-answer">

      Это государственные деньги, не коммерческие. В будущем,
      если Starship выйдет на поток, цена может упасть до
      <strong>$200 000</strong>.
    </div>
  </details>

  <details class="rd-faq-item">
    <summary>
      <span>Что случится, если экипаж не долетит?</span>
      <span class="rd-faq-icon">▸</span>
    </summary>
    <div class="rd-faq-answer">
      Есть <strong>план «Б»</strong>: если что-то пойдёт не так на подлёте,
      корабль может обогнуть Марс и вернуться на Землю по длинной
      траектории. Это займёт <strong>2–3 года</strong>, но
      экипаж останется жив.
    </div>
  </details>

  <details class="rd-faq-item">
    <summary>
      <span>Можно ли лететь зимой?</span>
      <span class="rd-faq-icon">▸</span>
    </summary>
    <div class="rd-faq-answer">
      Сезонов в космосе нет — там всегда холод и вакуум. Но на Земле
      погодные условия на космодроме влияют на старт. Зимой
      бывают <strong>ветра и метели</strong>, которые могут отложить
      запуск на несколько дней.
    </div>
  </details>

  <details class="rd-faq-item">
    <summary>
      <span>Что экипаж ест в пути?</span>
      <span class="rd-faq-icon">▸</span>
    </summary>
    <div class="rd-faq-answer">

      Плюс небольшой запас свежих овощей из <strong>мини-теплицы</strong>.

/* ═══ SCROLL OBSERVE ═══ */
function initObserve(){
  var items = document.querySelectorAll('.rd-observe');
  if (!items.length) return;
  if (!('IntersectionObserver' in window)){
    items.forEach(function(el){ el.classList.add('rd-visible'); });
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        e.target.classList.add('rd-visible');
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.1, rootMargin: '0px 0px -40px 0px' });
  items.forEach(function(el){ io.observe(el); });
}

/* ═══ СЧЁТЧИКИ ═══ */
function animateCounter(el){
  var target = parseFloat(el.dataset.target || '0');
  var format = el.dataset.format;
  var duration = 1800;
  var start = performance.now();
  function formatNum(n){
    var s = Math.round(n).toString();
    if (format === 'space') return s.replace(/\B(?=(\d{3})+(?!\d))/g, ' ');
    return s;
  }
  function tick(now){
    var p = Math.min((now - start) / duration, 1);
    var eased = 1 - Math.pow(1 - p, 3);
    var val = target * eased;
    el.textContent = formatNum(val);
    if (p < 1) requestAnimationFrame(tick);
    else el.textContent = formatNum(target);
  }
  requestAnimationFrame(tick);
}
function initCounters(){
  var counters = document.querySelectorAll('.rd-counter');
  if (!counters.length) return;
  if (!('IntersectionObserver' in window)){
    counters.forEach(animateCounter);
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        animateCounter(e.target);
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.5 });
  counters.forEach(function(el){ io.observe(el); });
}

function initWindowSim(){
  var slider = document.getElementById('rd-window');
  if (!slider) return;

  var winEl = document.getElementById('rd-window-value');
  var nextEl = document.getElementById('rd-next-window');
  var flightEl = document.getElementById('rd-flight-time');
  var arriveEl = document.getElementById('rd-arrival');
  var returnEl = document.getElementById('rd-return');

  // Окна старта: 2033, 2035, 2037, 2038, 2040...
  // Реальные окна: 2033, 2035 (июль), 2037 (сентябрь), 2039, 2041...
  var WINDOWS = [2033, 2035, 2037, 2039, 2041, 2043, 2045, 2047, 2049];

  function update(){
    var year = parseInt(slider.value, 10) || 2033;
    winEl.textContent = year;

    // Находим ближайшее окно >= year
    var next = WINDOWS[0];
    for (var i = 0; i < WINDOWS.length; i++){
      if (WINDOWS[i] >= year){ next = WINDOWS[i]; break; }
    }

    // Время полёта зависит от взаимного положения планет
    var flight = 180 + Math.round((year - 2033) * 0.5);
    if (flight > 240) flight = 240;
    if (flight < 180) flight = 180;

    // Дата прибытия (старт в июле, полёт N дней)
    var arrival = next + 1;

    // Обратный рейс — только через 26 месяцев после прибытия
    var returnY = arrival + 2;

    nextEl.textContent = next;
    flightEl.textContent = flight;
    arriveEl.textContent = arrival;
    returnEl.textContent = returnY;
  }

  slider.addEventListener('input', update);
  update();
}

function initFuelCalc(){
  var slider = document.getElementById('rd-mass');
  if (!slider) return;

  var massEl = document.getElementById('rd-mass-value');
  var toMarsEl = document.getElementById('rd-fuel-to-mars');
  var returnEl = document.getElementById('rd-fuel-return');
  var costEl = document.getElementById('rd-fuel-cost');
  var yearsEl = document.getElementById('rd-fuel-years');

  // Отношение топлива к массе корабля
  var FUEL_TO_MARS_RATIO = 0.87;    // 87% массы — топливо
  var FUEL_RETURN_RATIO = 0.45;     // 45% — если заправиться на Марсе
  var COST_PER_TON = 1000;          // $1000 за тонну метана
  var PROD_PER_YEAR = 500;          // тонн метана в год (1 установка)

  function fmt(n){
    return Math.round(n).toString().replace(/\B(?=(\d{3})+(?!\d))/g, ' ');
  }

  function update(){
    var mass = parseInt(slider.value, 10) || 1000;
    massEl.textContent = mass;

    var fuelToMars = mass * FUEL_TO_MARS_RATIO;
    var fuelReturn = mass * FUEL_RETURN_RATIO;
    var cost = (fuelToMars + fuelReturn) * COST_PER_TON / 1000000; // млн $
    var years = Math.ceil(fuelReturn / PROD_PER_YEAR);

    toMarsEl.textContent = fmt(fuelToMars);
    returnEl.textContent = fmt(fuelReturn);
    costEl.textContent = cost.toFixed(1);
    yearsEl.textContent = years < 1 ? '<1' : years;
  }

  slider.addEventListener('input', update);
  update();
}

  var canvas = document.getElementById('rd-orbit-canvas');
  if (!canvas) return;

  var ctx = canvas.getContext('2d');
  var DPR = Math.min(window.devicePixelRatio || 1, 2);
  var W = 0, H = 0;
  var time = 0;

  function resize(){
    var rect = canvas.getBoundingClientRect();
    W = rect.width;
    H = rect.height;
    canvas.width = W * DPR;
    canvas.height = H * DPR;
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
  }

  // Параметры орбит (в пикселях от центра)
  // Земля: 1 оборот ≈ 365 дней, радиус 0.6 от max
  // Марс: 1 оборот ≈ 687 дней, радиус 0.95 от max
  // Пропорции радиусов реальные: Земля 1 а.е., Марс 1.52 а.е.

  var earthSpeed = 1 / 365;   // оборота в день
  var marsSpeed = 1 / 687;

  var earthPhase = Math.random() * Math.PI * 2;
  var marsPhase = Math.random() * Math.PI * 2;

  function draw(){
    ctx.clearRect(0, 0, W, H);

    var cx = W / 2;
    var cy = H / 2;
    var maxR = Math.min(W, H) * 0.44;
    var earthR = maxR * 0.6;
    var marsR = maxR * 0.95;

    // Орбиты
    ctx.strokeStyle = 'rgba(255,255,255,.1)';
    ctx.lineWidth = 1;
    ctx.setLineDash([3, 5]);

    ctx.beginPath();
    ctx.arc(cx, cy, earthR, 0, Math.PI * 2);
    ctx.stroke();

    ctx.beginPath();
    ctx.arc(cx, cy, marsR, 0, Math.PI * 2);
    ctx.stroke();

    ctx.setLineDash([]);

    // Солнце
    var sunGrad = ctx.createRadialGradient(cx, cy, 0, cx, cy, 40);
    sunGrad.addColorStop(0, 'rgba(255,220,100,1)');
    sunGrad.addColorStop(0.4, 'rgba(255,180,50,.6)');
    sunGrad.addColorStop(1, 'rgba(255,150,50,0)');
    ctx.fillStyle = sunGrad;
    ctx.beginPath();
    ctx.arc(cx, cy, 40, 0, Math.PI * 2);
    ctx.fill();

    ctx.fillStyle = '#f5d76e';
    ctx.beginPath();
    ctx.arc(cx, cy, 12, 0, Math.PI * 2);
    ctx.fill();

    // Земля
    var earthX = cx + Math.cos(earthPhase) * earthR;
    var earthY = cy + Math.sin(earthPhase) * earthR;

    var earthGlow = ctx.createRadialGradient(earthX, earthY, 0, earthX, earthY, 24);
    earthGlow.addColorStop(0, 'rgba(52,152,219,.9)');
    earthGlow.addColorStop(1, 'rgba(52,152,219,0)');
    ctx.fillStyle = earthGlow;
    ctx.beginPath();
    ctx.arc(earthX, earthY, 24, 0, Math.PI * 2);
    ctx.fill();

    ctx.fillStyle = '#3498db';
    ctx.beginPath();
    ctx.arc(earthX, earthY, 8, 0, Math.PI * 2);
    ctx.fill();

    ctx.fillStyle = '#fff';
    ctx.beginPath();
    ctx.arc(earthX - 2, earthY - 2, 3, 0, Math.PI * 2);
    ctx.fill();

    // Марс
    var marsX = cx + Math.cos(marsPhase) * marsR;
    var marsY = cy + Math.sin(marsPhase) * marsR;

    var marsGlow = ctx.createRadialGradient(marsX, marsY, 0, marsX, marsY, 22);
    marsGlow.addColorStop(0, 'rgba(231,76,60,.9)');
    marsGlow.addColorStop(1, 'rgba(231,76,60,0)');
    ctx.fillStyle = marsGlow;
    ctx.beginPath();
    ctx.arc(marsX, marsY, 22, 0, Math.PI * 2);
    ctx.fill();

    ctx.fillStyle = '#e74c3c';
    ctx.beginPath();
    ctx.arc(marsX, marsY, 7, 0, Math.PI * 2);
    ctx.fill();

    ctx.fillStyle = 'rgba(0,0,0,.3)';
    ctx.beginPath();
    ctx.arc(marsX + 1.5, marsY + 1.5, 3, 0, Math.PI * 2);
    ctx.fill();

    // Подписи
    ctx.fillStyle = 'rgba(52,152,219,.9)';
    ctx.font = 'bold 11px -apple-system, sans-serif';
    ctx.fillText('Земля', earthX + 14, earthY + 4);

    ctx.fillStyle = 'rgba(231,76,60,.9)';
    ctx.fillText('Марс', marsX + 12, marsY + 4);

    ctx.fillStyle = 'rgba(245,215,110,.9)';
    ctx.fillText('Солнце', cx + 18, cy - 16);

    // Обновление фаз
    earthPhase += earthSpeed * 3;
    marsPhase += marsSpeed * 3;
    time++;
  }

  var rafId = null;
  var reducedMotion = window.matchMedia && window.matchMedia('(prefers-reduced-motion: reduce)').matches;

  function loop(){
    draw();
    if (!reducedMotion) rafId = requestAnimationFrame(loop);
  }

  function start(){
    resize();
    if (reducedMotion){
      draw();
    } else {
      if (rafId) cancelAnimationFrame(rafId);
      loop();
    }
  }

  window.addEventListener('resize', function(){
    resize();
    if (reducedMotion) draw();
  });

  // Запуск когда элемент в зоне видимости
  if ('IntersectionObserver' in window){
    var io = new IntersectionObserver(function(entries){
      entries.forEach(function(e){
        if (e.isIntersecting){
          start();
          io.unobserve(e.target);
        }
      });
    }, { threshold: 0.2 });
    io.observe(canvas);
  } else {
    start();
  }
}
