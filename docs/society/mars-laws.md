<h2 class="md-h2 md-observe">🧊 Что происходит с телом</h2>
<p class="md-lead md-observe">
  Тело на Марсе ведёт себя <strong>иначе, чем на Земле</strong>. Вот что происходит
  в первые часы и дни после смерти.
</p>

<div class="md-physics md-observe">
  <div class="md-physics-item">
    <div class="md-physics-icon">🥶</div>
    <div class="md-physics-title">На поверхности (−63°C)</div>
    <div class="md-physics-text">
      Тело <strong>мгновенно замерзает</strong> и мумифицируется. Бактерии
      не работают при такой температуре. Тело может сохраняться
      <strong>столетиями</strong> — как в вечной мерзлоте.
    </div>
  </div>

  <div class="md-physics-item">
    <div class="md-physics-icon">🏠</div>
    <div class="md-physics-title">Внутри купола (+22°C)</div>
    <div class="md-physics-text">
      Обычные процессы: окоченение через 2-4 часа, разложение
      через 1-2 дня. Но в куполе <strong>нет мух и микробов</strong> с Земли —
      тело не гниёт так быстро, как на родине.
    </div>
  </div>

  <div class="md-physics-item">
    <div class="md-physics-icon">💧</div>
    <div class="md-physics-title">Низкое давление</div>
    <div class="md-physics-text">
      Если тело <strong>без скафандра</strong>, жидкости закипают
      мгновенно. Кровь превращается в пар, ткани высыхают за минуты.
      Это — <strong>быстрая мумификация</strong>.
    </div>
  </div>
</div>

<h2 class="md-h2 md-observe">❓ Частые вопросы</h2>
<div class="md-faq md-observe">
  <details class="md-faq-item">
    <summary><span>Можно ли похоронить человека в скафандре?</span><span class="md-faq-icon">▸</span></summary>
    <div class="md-faq-answer">
      Да, это даже <strong>логично</strong> — скафандр защищает тело от
      прямого контакта с реголитом. Но реголит всё равно
      <strong>токсичен</strong> (перхлораты). Тело будет медленно
      разлагаться внутри скафандра.
    </div>
  </details>

  <details class="md-faq-item">
    <summary><span>Что если смерть наступила вне базы?</span><span class="md-faq-icon">▸</span></summary>
    <div class="md-faq-answer">
      Спасательная операция <strong>запрещена</strong>, если она угрожает
      другим. Скафандр держит 4-6 часов. Если колонист ушёл дальше
      и не вернулся — его <strong>не спасают</strong>. Это правило
      прописано в контрактах.
    </div>
  </details>

  <details class="md-faq-item">
    <summary><span>Можно ли кремировать тело внутри базы?</span><span class="md-faq-icon">▸</span></summary>
    <div class="md-faq-answer">
      Опасно. Кремация даёт <strong>дым и CO₂</strong>, что нарушает
      атмосферу купола. Обычно используют <strong>внешний реактор</strong>
      или оставляют тело за пределами базы.
    </div>
  </details>

  <details class="md-faq-item">
    <summary><span>Что скажут родным?</span><span class="md-faq-icon">▸</span></summary>
    <div class="md-faq-answer">
      Родным сообщит <strong>служба NASA/SpaceX</strong> через 22 минуты
      после подтверждения. Причина: <strong>нельзя скрывать</strong>,
      но нужно дать команде время принять факт.
    </div>
  </details>

  <details class="md-faq-item">
    <summary><span>Тело может «ожить» через годы?</span><span class="md-faq-icon">▸</span></summary>
    <div class="md-faq-answer">
      В вечной мерзлоте Марса тело сохранится <strong>как в холодильнике</strong>.
      Если через 200 лет научатся воскрешать (крионика) — тела будут
      в идеальном состоянии. Но это <strong>фантастика</strong>, не наука.
    </div>
  </details>

<script>
(function(){
'use strict';
if (window.__deathLoaded) return;
window.__deathLoaded = true;

function initObserve(){
  var items = document.querySelectorAll('.md-observe');
  if (!items.length) return;
  if (!('IntersectionObserver' in window)){
    items.forEach(function(el){ el.classList.add('md-visible'); });
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        e.target.classList.add('md-visible');
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.1, rootMargin: '0px 0px -40px 0px' });
  items.forEach(function(el){ io.observe(el); });
}

function animateCounter(el){
  var target = parseFloat(el.dataset.target || '0');
  var duration = 1800;
  var start = performance.now();
  function tick(now){
    var p = Math.min((now - start) / duration, 1);
    var eased = 1 - Math.pow(1 - p, 3);
    el.textContent = Math.round(target * eased).toString();
    if (p < 1) requestAnimationFrame(tick);
    else el.textContent = target.toString();
  }
  requestAnimationFrame(tick);
}

function initCounters(){
  var counters = document.querySelectorAll('.md-counter');
  if (!counters.length) return;
  if (!('IntersectionObserver' in window)){
    counters.forEach(animateCounter);
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        animateCounter(e.target);
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.5 });
  counters.forEach(function(el){ io.observe(el); });
}

function init(){
  initObserve();
  initCounters();
  console.log('⚰️ Что будет, если умереть на Марсе — загружено');
}

if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', init);
else init();

})();
</script>
