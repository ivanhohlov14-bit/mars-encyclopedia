<h2 class="sp-h2 sp-observe">
  <span class="sp-h2-num">04</span>
  Проблемы: что мешает спорту на Марсе
</h2>

<div class="sp-problems sp-observe">

  <div class="sp-problem-card">
    <div class="sp-problem-icon">🥶</div>
    <div class="sp-problem-title">Холод −63°C</div>
    <div class="sp-problem-text">
      На поверхности Марса <strong>средняя температура −63°C</strong>.
      Бегать в скафандре — как бегать в холодильнике. Нужны
      <strong>подогреваемые костюмы</strong> и короткие забеги.
    </div>
  </div>

  <div class="sp-problem-card">
    <div class="sp-problem-icon">💨</div>
    <div class="sp-problem-title">Пыль и песок</div>
    <div class="sp-problem-text">
      Реголит <strong>токсичен</strong> и забивает механизмы. Пыль
      везде: в лёгких, в суставах, в приводах. Нужны
      <strong>герметичные стадионы</strong> внутри куполов.
    </div>
  </div>

  <div class="sp-problem-card">
    <div class="sp-problem-icon">🦴</div>
    <div class="sp-problem-title">Атрофия мышц</div>
    <div class="sp-problem-text">
      В низкой гравитации <strong>мышцы слабеют</strong>, кости теряют
      кальций. Спорт на Марсе — не развлечение, а <strong>терапия
      выживания</strong>. Космонавты обязаны тренироваться 2 часа в день.
    </div>
  </div>

  <div class="sp-problem-card">
    <div class="sp-problem-icon">🏟️</div>
    <div class="sp-problem-title">Помещения</div>
    <div class="sp-problem-text">
      Играть под открытым небом <strong>невозможно</strong>. Нужны
      огромные герметичные купола. Первый марсианский стадион

<!-- FAQ -->
<h2 class="sp-h2 sp-observe">❓ Частые вопросы</h2>
<div class="sp-faq sp-observe">

  <details class="sp-faq-item">
    <summary><span>Можно ли заниматься спортом на Марсе без скафандра?</span><span class="sp-faq-icon">▸</span></summary>
    <div class="sp-faq-answer">
      <strong>Нет.</strong> Атмосфера Марса — 95% CO₂ и давление в 170 раз
      ниже земного. Без скафандра человек умирает за <strong>1-2 минуты</strong>.
      Все виды спорта — только в <strong>герметичных куполах</strong> или
      в специальных костюмах.
    </div>
  </details>

  <details class="sp-faq-item">
    <summary><span>Прыгну ли я реально в 2.6 раза выше?</span><span class="sp-faq-icon">▸</span></summary>
    <div class="sp-faq-answer">
      <strong>Теоретически да</strong>, но есть нюансы. Во-первых, скафандр
      весит <strong>50-100 кг</strong>. Во-вторых, мышцы в полёте теряют
      массу — сила падает. Реальный прирост — <strong>2.0-2.3 раза</strong>,
      если ты не тренирован. Если тренирован — до <strong>2.6 раз</strong>.
    </div>
  </details>

  <details class="sp-faq-item">
    <summary><span>Какой спорт станет самым популярным?</span><span class="sp-faq-icon">▸</span></summary>
    <div class="sp-faq-answer">
      Внутри купола — <strong>баскетбол</strong> (зрелищные слэм-данки)
      и <strong>гимнастика</strong> (акробатика). Снаружи —
      <strong>реактивные гонки</strong> в каньонах. А ещё — <strong>футбол
      с мячом, который улетает за пределы поля</strong>.
    </div>
  </details>

  <details class="sp-faq-item">
    <summary><span>Что будет с рекордами Земли?</span><span class="sp-faq-icon">▸</span></summary>
    <div class="sp-faq-answer">
      Будут <strong>отдельные категории</strong>. Как сейчас есть рекорды
      «в помещении» и «на открытом воздухе», так появятся «Земля / Луна /
      Марс». Мировые рекорды Земли не побить — но можно поставить
      <strong>марсианские</strong>.
    </div>
  </details>

  <details class="sp-faq-item">
    <summary><span>Сколько спортсменов сейчас на Марсе?</span><span class="sp-faq-icon">▸</span></summary>
    <div class="sp-faq-answer">
      <strong>Ноль.</strong> Первая пилотируемая миссия запланирована
      на <strong>2030-е</strong>. А первая марсианская Олимпиада —
      не раньше <strong>2050-х</strong>. Так что ты пока можешь только
      тренироваться на Земле.
    </div>
  </details>

  <details class="sp-faq-item">
    <summary><span>Есть ли спорт на МКС?</span><span class="sp-faq-icon">▸</span></summary>
    <div class="sp-faq-answer">
      <strong>Да, но это не игры</strong> — тренировки. Астронавты
      <strong>2 часа в день</strong> крутят педали и бегут на дорожке
      с эспандерами. Иначе мышцы атрофируются за <strong>6 месяцев</strong>.
      На МКС нельзя играть в футбол — мяч просто улетает.
    </div>
  </details>

  <details class="sp-faq-item">
    <summary><span>Кто первый марсианский олимпиец?</span><span class="sp-faq-icon">▸</span></summary>
    <div class="sp-faq-answer">
      Пока <strong>никто</strong>. Но если ты всерьёз хочешь — начни
      сейчас: <strong>учись на инженера или врача</strong>, занимайся
      спортом, подтяни здоровье. Возможно, через 30 лет <strong>ты
      станешь первым</strong>.
    </div>
  </details>

</div>

      спортсменов — он будет <strong>другим</strong>. Спорт станет

function initObserve(){
  var items = document.querySelectorAll('.sp-observe');
  if (!items.length) return;
  if (!('IntersectionObserver' in window)){
    items.forEach(function(el){ el.classList.add('sp-visible'); });
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        e.target.classList.add('sp-visible');
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.1, rootMargin: '0px 0px -40px 0px' });
  items.forEach(function(el){ io.observe(el); });
}

/* ═══ COUNTERS ═══ */
function animateCounter(el){
  var target = parseFloat(el.dataset.target || '0');
  var decimals = parseInt(el.dataset.decimals || '0', 10);
  var duration = 1800;
  var start = performance.now();
  function tick(now){
    var p = Math.min((now - start) / duration, 1);
    var eased = 1 - Math.pow(1 - p, 3);
    var val = target * eased;
    el.textContent = decimals > 0 ? val.toFixed(decimals) : Math.round(val).toString();
    if (p < 1) requestAnimationFrame(tick);
    else el.textContent = decimals > 0 ? target.toFixed(decimals) : target.toString();
  }
  requestAnimationFrame(tick);
}
function initCounters(){
  var counters = document.querySelectorAll('.sp-counter');
  if (!counters.length) return;
  if (!('IntersectionObserver' in window)){
    counters.forEach(animateCounter);
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        animateCounter(e.target);
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.5 });
  counters.forEach(function(el){ io.observe(el); });
}

    kickMoon: document.getElementById('sp-kick-moon')
  };

  if (!inputs.highJump) return;

  var RATIO_MARS = 9.81 / 3.71; // 2.64
  var RATIO_MOON = 9.81 / 1.62; // 6.06

  function update(){
    var h = parseFloat(inputs.highJump.value) || 0;
    var l = parseFloat(inputs.longJump.value) || 0;
    var b = parseFloat(inputs.bench.value) || 0;
    var k = parseFloat(inputs.kick.value) || 0;

    outputs.highMars.textContent = Math.round(h * RATIO_MARS);
    outputs.highMoon.textContent = Math.round(h * RATIO_MOON);
    outputs.longMars.textContent = Math.round(l * RATIO_MARS);
    outputs.longMoon.textContent = Math.round(l * RATIO_MOON);
    outputs.benchMars.textContent = Math.round(b * RATIO_MARS);
    outputs.benchMoon.textContent = Math.round(b * RATIO_MOON);
    outputs.kickMars.textContent = Math.round(k * RATIO_MARS);
    outputs.kickMoon.textContent = Math.round(k * RATIO_MOON);
  }

  Object.keys(inputs).forEach(function(k){
    if (inputs[k]) inputs[k].addEventListener('input', update);
  });
  update();
}

/* ═══ СИМУЛЯТОР ПРЫЖКА ═══ */
function initSimulator(){
  var tabs = document.querySelectorAll('.sp-sim-tab');
  var jumper = document.getElementById('sp-jumper');
  var heightBox = document.getElementById('sp-sim-height');
  var heightVal = document.getElementById('sp-sim-height-val');
  var jumpBtn = document.getElementById('sp-jump-btn');
  var resultVal = document.getElementById('sp-sim-result-val');
  var infoBox = document.getElementById('sp-sim-info');

  if (!jumper || !jumpBtn) return;

  var currentPlanet = 'earth';
  var isJumping = false;

  // Базовый прыжок человека: 0.6 м на Земле
  var BASE_JUMP = 0.6; // метра

  // Визуальная шкала: 4 метра = 100% высоты сцены (минус 60px земли)
  // Stage height = 400px, minus 60px ground = 340px полезной высоты
  var STAGE_USABLE = 340;
  var MAX_METERS = 4; // 4 метра = 100% шкалы

  function getJumpHeightMeters(planet){
    var gravityRatio = G.earth.g / G[planet].g;
    return BASE_JUMP * gravityRatio;
  }

  function metersToPercent(m){
    return (m / MAX_METERS) * 100;
  }

  function updateResult(){
    var m = getJumpHeightMeters(currentPlanet);
    resultVal.textContent = m.toFixed(2) + ' м';
    infoBox.innerHTML = '💡 На ' + G[currentPlanet].name + ' (гравитация ' +
      (G[currentPlanet].g / G.earth.g).toFixed(2) + 'g) обычный человек прыгнет ' +
      '<strong>' + m.toFixed(2) + ' м</strong> в высоту. ' +
      'Земной прыжок: 0.60 м.';
  }

  function updateTabs(planet){
    tabs.forEach(function(t){
      t.classList.toggle('active', t.dataset.planet === planet);
    });
  }

  tabs.forEach(function(tab){
    tab.addEventListener('click', function(){
      currentPlanet = tab.dataset.planet;
      updateTabs(currentPlanet);
      updateResult();
      jumper.style.bottom = '60px';
    });
  });

  jumpBtn.addEventListener('click', function(){
    if (isJumping) return;
    isJumping = true;
    jumpBtn.disabled = true;

    var heightM = getJumpHeightMeters(currentPlanet);
    var percent = metersToPercent(heightM);
    // Максимум 90% от сцены (чтобы не улетел за пределы)
    percent = Math.min(percent, 90);

    // Устанавливаем CSS-переменную для keyframes
    jumper.style.setProperty('--jump-height', percent + '%');

    // Класс для анимации
    jumper.classList.remove('jumping');
    void jumper.offsetWidth;
    jumper.classList.add('jumping');

    heightBox.classList.add('active');
    heightVal.textContent = heightM.toFixed(2) + ' м';

    // Параллельное обновление счётчика высоты
    var startTime = performance.now();
    var duration = 1400;

    function tick(now){
      var p = Math.min((now - startTime) / duration, 1);
      // Парабола: 0 → 1 → 0
      var parabola = 4 * p * (1 - p);
      // Пик параболы = 1 при p=0.5
      var currentHeight = heightM * (p < 0.5 ? (p * 2) : ((1 - p) * 2));
      // Реальная высота следует параболе — умножаем на пик
      heightVal.textContent = (heightM * (p < 0.5 ? (p * 2) : ((1 - p) * 2))).toFixed(2) + ' м';

      if (p < 1) requestAnimationFrame(tick);
      else {
        heightVal.textContent = heightM.toFixed(2) + ' м';
      }
    }
    requestAnimationFrame(tick);

    setTimeout(function(){
      isJumping = false;
      jumpBtn.disabled = false;
      jumper.classList.remove('jumping');
      jumper.style.bottom = '60px';
      heightBox.classList.remove('active');
      heightVal.textContent = '0.00 м';
    }, 1500);
  });

  updateResult();
}
