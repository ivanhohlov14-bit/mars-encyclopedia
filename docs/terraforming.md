<h2 class="tf-h2 tf-observe">
  <span class="tf-h2-num">01</span>
  Что у Марса и Земли общего — и что разное
</h2>

<div class="tf-section tf-observe">
  <div class="tf-section-img">
    <img src="/assets/images/mars-earth-comparison.jpeg" 
         alt="Сравнение Марса и Земли" loading="lazy">
    <div class="tf-section-img-badge">🌍 Сравнение</div>
  </div>
  <div class="tf-section-text">
    <p>
      Марс и Земля — <strong>сёстры</strong>. Похожий размер (в 2 раза
      меньше), твёрдая поверхность, наклон оси почти такой же (25° против
      23.5°) — значит есть времена года.
    </p>
    <p>
      Но три главных отличия делают Марс <strong>непригодным для жизни</strong>:
      <strong>нет магнитного поля</strong> (атмосферу сдувает солнечный
      ветер), <strong>атмосфера в 170 раз тоньше</strong> (давление как
      на высоте 35 км) и <strong>холодно</strong> — в среднем −63 °C.
    </p>
    <div class="tf-fact-box">
      <div class="tf-fact-box-icon">🌡️</div>
      <div class="tf-fact-box-body">
        <strong>Если бы Марс был больше</strong> в 3–4 раза — у него было бы
        магнитное поле. Тогда он мог бы быть <strong>второй Землёй</strong>.
        Но размер планеты <strong>изменить нельзя</strong>.
      </div>
    </div>
  </div>
</div>

<h2 class="tf-h2 tf-observe">
  <span class="tf-h2-num">02</span>
  Проблема: атмосфера улетучивается
</h2>

<div class="tf-section tf-section-reverse tf-observe">
  <div class="tf-section-img">
    <img src="/assets/images/Mars_sunset_PIA00920.jpg" 
         alt="Закат на Марсе" loading="lazy">
    <div class="tf-section-img-badge">🌅 Атмосфера</div>
  </div>
  <div class="tf-section-text">
    <p>
      Когда-то атмосфера Марса была <strong>плотной</strong> — возможно,
      как на Земле. Но ядро планеты остыло, магнитное поле исчезло, и
      солнечный ветер <strong>сдул 99% газа</strong> в космос.
    </p>
    <p>
      Именно поэтому <strong>небо на закате синее, а не красное</strong> —
      пыль рассеивает свет по-другому. Это след древней атмосферы,
      которую мы могли бы вернуть.
    </p>
    <div class="tf-fact-box">
      <div class="tf-fact-box-icon">🚀</div>
      <div class="tf-fact-box-body">
        <strong>Решение:</strong> построить <strong>магнитный щит</strong>
        в точке L1 (между Солнцем и Марсом) — как зонт от солнечного
        ветра. Концепция предложена NASA в 2017 году. Технически
        <strong>реализуема уже сейчас</strong>.
      </div>
    </div>
  </div>
</div>

/* ═══ SCROLL OBSERVE ═══ */
function initObserve(){
  var items = document.querySelectorAll('.tf-observe');
  if (!items.length) return;
  if (!('IntersectionObserver' in window)){
    items.forEach(function(el){ el.classList.add('tf-visible'); });
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        e.target.classList.add('tf-visible');
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.1, rootMargin: '0px 0px -40px 0px' });
  items.forEach(function(el){ io.observe(el); });
}

/* ═══ СЧЁТЧИКИ ═══ */
function animateCounter(el){
  var target = parseFloat(el.dataset.target || '0');
  var duration = 1800;
  var start = performance.now();
  function tick(now){
    var p = Math.min((now - start) / duration, 1);
    var eased = 1 - Math.pow(1 - p, 3);
    el.textContent = Math.round(target * eased).toString();
    if (p < 1) requestAnimationFrame(tick);
    else el.textContent = target.toString();
  }
  requestAnimationFrame(tick);
}
function initCounters(){
  var counters = document.querySelectorAll('.tf-counter');
  if (!counters.length) return;
  if (!('IntersectionObserver' in window)){
    counters.forEach(animateCounter);
    return;
  }
  var io = new IntersectionObserver(function(entries){
    entries.forEach(function(e){
      if (e.isIntersecting){
        animateCounter(e.target);
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.5 });
  counters.forEach(function(el){ io.observe(el); });
}

function initTempSim(){
  var slider = document.getElementById('tf-co2');
  if (!slider) return;

  var co2El = document.getElementById('tf-co2-value');
  var tempEl = document.getElementById('tf-temp');
  var pressureEl = document.getElementById('tf-pressure');
  var waterEl = document.getElementById('tf-water');
  var suitEl = document.getElementById('tf-suit');
  var pctEl = document.getElementById('tf-progress-pct');
  var barEl = document.getElementById('tf-progress-bar');

  // Модель NASA (упрощённая)
  // База: T = -63°C, P = 6 мбар, вода = 0%
  // Каждые 10× CO2 → +15°C, +20 мбар

  function update(){
    var mult = parseInt(slider.value, 10) || 1;
    co2El.textContent = mult;

    // Логарифмическая модель: log(mult)/log(10) — сколько "10×"
    var log10 = Math.log10(mult);
    var tempDelta = log10 * 15;
    var pressDelta = log10 * 20;

    var temp = -63 + tempDelta;
    var pressure = 6 + pressDelta;

    // Вода: при T > 0 появляется вода
    var water = 0;
    if (temp > -10) water = Math.min((temp + 10) * 3, 30);

    // Скафандр
    var suit = pressure < 250 ? 'Да' : (temp > -10 ? 'Нет' : 'Маска');

    // Прогресс: считаем по логарифму. 100× = 100% если допустить
    var progress = Math.min(log10 / 2 * 100, 100);

    tempEl.textContent = temp.toFixed(0);
    pressureEl.textContent = Math.round(pressure);
    waterEl.textContent = Math.round(water);
    suitEl.textContent = suit;
    pctEl.textContent = Math.round(progress) + '%';
    barEl.style.width = progress + '%';
  }

  slider.addEventListener('input', update);
  update();
}
